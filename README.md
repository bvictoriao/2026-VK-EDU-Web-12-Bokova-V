# 2026-VK-EDU-Web-12-Bokova-V

Учебный проект курса веб-разработки VK Education.

ДЗ1: статическая вёрстка сервиса вопросов и ответов на HTML, CSS и Bootstrap.

Вёрстка будет находиться в `public/`, локальные стили, скрипты и изображения — в `public/static/`.
Инструкция открытия страниц будет добавлена после создания вёрстки.
