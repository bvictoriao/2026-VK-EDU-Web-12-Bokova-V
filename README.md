# 2026-VK-EDU-Web-12-Bokova-V

Учебный проект курса веб-разработки VK Education.

ДЗ1: статическая вёрстка сервиса вопросов и ответов на HTML, CSS и Bootstrap.

## Как открыть

Откройте `public/index.html` в браузере двойным щелчком либо через пункт
«Открыть с помощью». Из PyCharm можно открыть HTML-файл и выбрать
Open in Browser («Открыть в браузере»).

Для ДЗ1 сервер, Python и установка пакетов не требуются. Все стили и изображения
хранятся локально; интернет для просмотра не нужен.

## Страницы

| Файл | Содержимое |
| --- | --- |
| [base.html](public/base.html) | Общий каркас: шапка, две колонки, подвал |
| [index.html](public/index.html) | Список вопросов, три состояния голосования, пагинация |
| [question.html](public/question.html) | Вопрос, ответы, отметка правильного ответа, форма ответа |
| [ask.html](public/ask.html) | Форма создания вопроса |
| [login.html](public/login.html) | Форма входа |
| [signup.html](public/signup.html) | Форма регистрации и выбор аватарки |
| [profile.html](public/profile.html) | Настройки email, никнейма и аватарки |

В шапке страницы профиля показан авторизованный пользователь, на остальных
страницах — ссылки входа и регистрации. Чтобы посмотреть профиль, откройте
`public/profile.html` напрямую или по ссылке в этой таблице.

## Структура

```text
public/
  base.html
  index.html
  question.html
  ask.html
  login.html
  signup.html
  profile.html
  static/
    css/    # Bootstrap 5.3.8 и собственный style.css
    js/     # папка для скриптов, пока не используются
    img/    # локальные аватарка и favicon
```

Вариант ДЗ1 — обычный HTML: общий каркас скопирован в страницы согласно
примеру первого семинара. Используются HTML, CSS и Bootstrap без сборщика.

## Статические состояния

- Вопросы, ответы, рейтинги и данные пользователя — демонстрационные.
- Ошибки в формах показаны постоянно как примеры оформления. Они не меняются
  при вводе данных.
- Кнопки отправки форм, голосования и выбора правильного ответа не обрабатывают
  действия и не сохраняют данные.
- Поле выбора аватарки позволяет выбрать файл, но не загружает его на сервер
  и не обновляет изображение на странице.
- Пагинация вопросов меняет параметр `?page=…`, но содержимое остаётся прежним.
  У трёх ответов показан вариант пагинации с одной страницей.
- Поиск пока не выполняется. Ссылки участников с `href="#"` — заглушки.
- Ссылка «Выйти» в профиле открывает главную с гостевой шапкой; настоящей
  авторизации пока нет.
- `hot.html` и `tag.html` пока не созданы. Ссылки на них оставлены для следующего
  этапа: ДЗ1 прямо разрешает проработать эти страницы в ДЗ2.

## Проверка в браузере

В DevTools включите режим адаптивного экрана и проверьте ширины 375, 768 и 1200 px.
Проверяйте шапку, поля и кнопки форм, карточки, отсутствие горизонтального скролла.
При ширине менее 992 px боковая колонка располагается под основным содержимым.
На коротких страницах подвал должен оставаться внизу окна.

Вёрстка шести страниц проверена в Chrome на ширинах 375, 768 и 1200 px.
Проверены перенос шапки, расположение боковой колонки, карточки, формы и подвал.
Локальные CSS и изображения присутствуют; ссылки между готовыми страницами
указывают на существующие файлы.
